## Purpose

定义 TraceItem 在 Web、Mobile 与 Server 三端之间共用常量数据的单一数据源（`shared/`）规范、跨端映射一致性要求及同步校验机制，消除多端重复硬编码与数据漂移问题。

## ADDED Requirements

### Requirement: 跨端共用常量单一数据源目录
系统 MUST 在仓库根目录维护 `shared/` 目录作为多端共用静态常量的唯一权威数据源，统一存放分类 Emoji 图标库（含分组与预设分类映射）、空间图腾图标库（房屋与房间）、主题色板配置、系统默认预设分类模板及多媒体端侧压缩参数。

#### Scenario: 新增或修改分类 Emoji 图标仅编辑共享文件
- **WHEN** 开发者在共享分类 Emoji 配置文件中新增、调整或映射任意分类图标，并执行同步流程
- **THEN** Web 端与 Mobile 端的分类图标选择器及管理员模板页 SHALL 展示完全一致的分组与图标列表，无需手动在多端重复修改硬编码数组。

#### Scenario: 房屋与房间空间图腾双端一致
- **WHEN** 用户在 Web 端或 Mobile 端创建或编辑房屋、功能房间
- **THEN** 两端展示的房屋图腾（10 款）与功能房间图腾（合并去重后的统一完整集合）SHALL 保持完全一致的图标与中文语义标签。

### Requirement: 主题色板与系统预设常量三端同步
Web 端、Mobile 端与 Server 端 MUST 消费源自 `shared/` 的同一套多巴胺主题定义、14 套系统预设分类模板与多媒体规格参数，确保多端视觉主题、新用户初始化分类及端侧压缩阈值严格对齐。

#### Scenario: 多巴胺主题色板在双端保持一致
- **WHEN** 用户在 Web 端或 Mobile 端打开主题设置界面并切换任一多巴胺主题
- **THEN** 7 套核心多巴胺主题（阳光暖橙、草莓甜心、薄荷清柠、星空城堡、雅致原木、梦幻薰衣草、赛博霓虹）的名称、图标、描述及主辅色值在两端 SHALL 完全一致。

#### Scenario: 共享同步校验拦截未同步的生成代码
- **WHEN** 共享源文件被修改但未执行同步生成，导致目标端生成常量与共享源文件不一致时
- **THEN** 同步校验命令或自动化测试 SHALL 返回非零错误并指出具体存在差异的目标文件。
