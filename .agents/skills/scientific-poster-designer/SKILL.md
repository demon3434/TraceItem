# 青少年科技创新大赛展板设计与渲染规范 (Scientific Poster Designer)

本技能专为青少年科技创新大赛（科学研究论文、发明制作等）电子展牌/展板提供专业的内容策划、美学排版及印刷级图像渲染。

## 一、官方比赛硬性规范与红线 (Official Hard Rules)

1. **尺寸与物理规格**：
   - **单面尺寸**：宽 42cm × 长 59cm（国际标准 **A2** 竖向画幅，宽高比约为 1 : 1.405）；
   - **格式与分辨率**：JPG 格式，印刷标准要求分辨率 >= 300 dpi（像素尺寸约为 4961 x 6969 px）；
   - **命名规则**：必须以作品编号命名（如 文小067.jpg）。

2. **左上角标牌红线**：
   - 左上角必须带有作品编号框，规格为：长 6cm x 2.5cm；
   - 配色与字体：**蓝色背景、黑体、小初字号、白色文字**；
   - 严禁修改此编号框的位置与色彩基调。

3. **双盲评审红线（严防违规出局）**：
   - 展板全文**绝对严禁**出现参赛选手姓名、指导老师姓名、所在学校名称、校徽 LOGO 等任何可识别身份的信息！
   - 一旦违规，组委会直接按废除参评资格处理。

## 二、小学生“研究论文类（文小）”核心板块架构

针对小学高年级（3~6年级）科学研究论文，必须展现“提出真实生活问题 -> 科学假设 -> 研究方法与动手过程 -> 实验对比数据 -> 结论与反思”的完整闭环，拒绝虚假大空的工程师原型。

1. 突出“AI 工具协同开发”（评审亮点）：
   - 小学生是提出生活需求与体验标准的“小产品经理”；
   - AI 是智能编程伙伴，通过拷问澄清（GLOSSARY/ADR）和 OpenSpec 增量精修 Kotlin 代码；
   - 小学生亲自在真机和模拟器测试、对比数据、得出结论。

2. 视觉美学标准：
   - 拒绝灰暗冷硬，采用阳光活力多巴胺色板，温润大圆角；
   - 图文并茂，配备手机真机运行截图与实验数据图表；
   - 字号分明，确保展板印刷放大后清晰易读。
